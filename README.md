# Government AI Platform

ديمو تفاعلي لمفاهيم حكومية رقمية: **حياة • حق • موعد**.

## المفاهيم

- **حياة:** Government Life Journey Engine — ينظم الخدمات الحكومية حول أحداث حياة المواطن.
- **حق:** Eligibility Discovery Engine — يكتشف الاستحقاقات المحتملة ويشرح سبب ظهورها.
- **موعد:** Government Timing Engine — يتوقع ضغط الطلب ويقترح نافذة خدمة أفضل.

## تشغيل الديمو

افتح `index.html` في متصفح حديث. لا توجد مكتبات خارجية أو خادم مطلوب.

> جميع البيانات في الديمو وهمية. الهدف عرض الفكرة وتجربة UX، وليس تمثيل تكامل حكومي حقيقي.
